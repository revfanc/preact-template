# Agreement 开发约束

适用于 `apps/agreement`。新增或修改协议前，先阅读本文件和 [README](./README.md)。这里约束页面开发；运行方式、页面示例和部署说明以 README 为准。

## 页面与内容

- 新增协议统一放在 `src/pages/<协议名>/index.tsx`，目录名使用小写英文、数字和连字符，可按业务使用多级目录。已有协议 URL 保持稳定，不因标题变化自动改名。
- 每页导出非空字符串 `title` 和默认页面组件，正文使用一个 `<h1>{title}</h1>`，条款按层级使用标题、段落和列表。`App` 已提供 `main` 容器，页面不重复包裹 `main`。
- `pages` 只放路由页面；辅助组件放在 `src/components/<组件名>/index.tsx`，其他辅助模块也放在 `pages` 外。不要依赖下划线文件名来忽略路由。
- 正文、公司名称、金额、日期、编号和链接以用户提供的材料为准，不擅自改写、删减或补全。缺少业务内容时明确指出缺项；只有明确要求示例内容时才编写示例，并标明用途。

## 静态渲染与交互

- 固定正文必须包含在构建产物 HTML 中，禁用或延迟 JavaScript 时仍可阅读，不能等接口或 hydration 完成后才展示整篇协议。
- 页面及其依赖会在 Node 构建过程中执行。模块顶层、组件 render 和初始状态计算不访问 `window`、`document`、浏览器缓存等 API，也不启动请求、监听器或定时器。
- 浏览器查询参数、缓存、动态请求和事件监听放到客户端 effect 或事件中；effect 清理监听器、定时器及待处理异步任务。浏览器首次渲染与静态 HTML 保持一致，避免当前时间、随机数、设备判断造成内容差异。
- 少量动态字段需要明确加载与失败状态，不用编造的公司、金额等默认值填充。依赖 JavaScript 的按钮在接管前保持不可操作；协议之间用普通 `<a>` 完整导航，链接遵循 `BASE_URL` 和正式尾斜杠约定。

## 样式与依赖

- 复用 `src/style.css` 的公共排版，主题覆盖放在 `src/theme.css`，使用 px 和响应式容器。新增专用样式需通过现有公共 CSS 入口引入，并限定作用范围，确保进入预渲染 HTML 的内联样式。
- 不在客户端挂载后才注入正文所需样式，不为单份协议另建 CSS 加载或内联方案。
- 共享能力通过工作区包的公开入口引入，并声明依赖；不导入 Landing 源码。按需使用现有请求能力，不复制请求封装；引入浏览器 API 或依赖时检查仓库兼容目标。

## 修改范围

- 普通新增协议只需新增页面及必要的内容、组件和样式，不手动维护路由列表，不逐页声明 `prerender`。本应用自动预渲染全部静态页面。
- 保持现有 SSG + hydration、完整页面导航和静态文件输出方式。普通新增协议不改 `main.tsx`、`app.tsx`、`routes.ts`、Vite 配置或共享构建插件，不引入 SPA Router。
- 不新增根首页、动态参数路由、SPA fallback 或静态 404 协议页。保留应用根 `index.html` 作为构建模板；未知生产地址由服务器返回 404。
- 若需求确实涉及架构或公共能力调整，说明原因和受影响范围，按该需求验证共享消费者；不要把架构改造混入普通文案修改。

## 验收

新增或修改协议页面后，在仓库根目录运行：

```sh
pnpm format:check
pnpm lint
pnpm --filter @apps/agreement check
pnpm --filter @apps/agreement build:test
pnpm --filter @apps/agreement build:prod
```

- 检查对应 `apps/agreement/dist/<协议路径>/index.html`，确认标题、正文和内联样式存在，内容与提供的材料一致。`dist` 以最后一次构建为准。
- 预览对应环境，直接打开新增 URL 并刷新；检查窄屏排版、长链接换行，以及禁用 JavaScript 时的固定正文。新增交互还需检查 hydration 后事件、加载失败与重试，并补充针对该行为的回归。
- 改动公共样式、入口或构建逻辑时，检查现有协议，运行 `pnpm exec vitest run tests/agreement-build.test.ts`，并按[质量说明](../../docs/quality.md)执行相关浏览器回归。纯文档修改只检查格式、链接和描述准确性。
- 交付时写明执行过的检查及尚未验证的项目；现代浏览器通过不代表最低版本设备已验收。

构建已拒绝动态路由和重复路径。目录组织、标题要求、文案准确性及修改范围还需遵守本文件并审查，不能把文档约定当作已有自动校验。
